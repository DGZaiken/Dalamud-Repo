# Dalamud-Repo
This repository acts as a centralized Repistory for things I might create.

## Current Plugins

[DMUModelHelper](https://github.com/DGZaiken/DMUModelHelper): This plugin gives Scaling Options for Bosses in DMU.

## Installation

First, open Dalamud's plugin installer by writing `/xlplugins` ingame, then go to Dalamud settings and add this custom repository to the list.

`https://raw.githubusercontent.com/DGZaiken/Dalamud-Repo/main/repo.json`
